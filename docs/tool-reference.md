# Tool Reference

These tools provide first-pass, public-safe business workflow review.

| Tool | Purpose |
| --- | --- |
| `analyze_business_context` | Summarizes business model, customer, offer, constraints, goals, and missing information. |
| `map_customer_touchpoints` | Reviews customer journey stages, trust moments, service recovery points, and review rules. |
| `identify_bottlenecks` | Identifies likely revenue, operations, customer experience, and trust/control bottlenecks. |
| `evaluate_ai_opportunities` | Evaluates possible AI assistance opportunities without assuming full autonomy. |
| `assess_trust_control_risks` | Reviews sensitive data, brand trust, money impact, expert judgment, and review needs. |
| `recommend_first_workflow` | Recommends a narrow, measurable, human-reviewable first workflow. |
| `generate_mini_report` | Creates a concise mini business system review. |
| `recommend_next_step` | Recommends a neutral next-step category. |
| `export_intake_packet` | Produces a structured intake packet for deeper review. |

Tool outputs are first-pass recommendations based only on the information provided.
