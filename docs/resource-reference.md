# Resource Reference

The MCP exposes public-safe resources that help users and AI clients understand the review.

| Resource | Purpose |
| --- | --- |
| `advisor://overview` | Explains what the advisor does. |
| `advisor://how-it-works` | Summarizes the review flow in business-facing language. |
| `advisor://readiness-guide` | Describes qualities of a good first workflow. |
| `advisor://sample-mini-report` | Provides a fictional mini report example. |
| `advisor://sample-intake-packet` | Provides a fictional intake packet example. |
| `advisor://privacy` | Explains the basic privacy boundary. |
