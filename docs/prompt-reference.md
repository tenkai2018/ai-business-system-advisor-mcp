# Prompt Reference

Use these prompts as entry points inside compatible MCP clients.

| Prompt | Use |
| --- | --- |
| `run_mini_business_system_review` | Run a first-pass review of a business and identify the safest first AI-human workflow. |
| `evaluate_ai_workflow_idea` | Evaluate whether an AI workflow idea is useful, safe, ready, and reviewable. |
| `prepare_diagnostic_intake` | Prepare structured context for a deeper business workflow review. |
| `governance_gap_snapshot` | Identify data boundaries, review rules, escalation rules, and quality controls. |

Prompts are public-safe and should be used with sanitized business summaries.
