# Privacy And Safety

AI Business System Advisor MCP is a first-pass business review tool.

Do not send:

- passwords
- API keys
- raw private customer records
- regulated data
- confidential contracts
- production credentials
- private customer identifiers

Use sanitized summaries and fictionalized examples when possible.

The public version does not intentionally persist submitted business context, send email, write to CRM systems, process payments, execute shell commands, or fetch arbitrary URLs from user input.

Outputs are not legal, financial, medical, HR, or compliance advice.
