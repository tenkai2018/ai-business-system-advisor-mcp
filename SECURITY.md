# Security

This MCP server is read-mostly in v0.1. It does not send email, write to a database, connect to CRM systems, fetch arbitrary URLs, or execute commands from user input.

Do not submit passwords, API keys, private customer records, medical records, financial account credentials, confidential contracts, or regulated data unless sanitized.

Reports are first-pass business reviews, not legal, financial, medical, HR, or compliance advice.
